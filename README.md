# FLA Gallery

FLA Gallery

Una piattaforma fotografica progettata
da zero, pixel dopo pixel.

Ogni scatto racconta una storia.
Ogni release aggiunge un capitolo.

## Obiettivi

- Pubblicare una nuova serata in pochi minuti.
- Offrire una navigazione semplice e veloce.
- Mettere le fotografie al centro dell'esperienza.
- Gestire in autonomia le gallerie senza dipendere da servizi esterni.
